Chrome extension for WhatsApp Web

Store Sync POS Messenger

Sends the customer messages queued in your Store Sync POS through your own WhatsApp Web, and saves your customers' replies back into the POS.

  • Version 1.103
  • Chrome and Edge
  • Needs a Store Sync POS account
How it works

Two jobs, running side by side

Your team queues messages in the POS as usual. The extension does the WhatsApp side, using the WhatsApp account signed in on that computer.

Sending queued messages

  1. Someone presses Start in the sidebar.
  2. The extension asks the POS for the next message waiting to be sent.
  3. It opens that customer's chat in WhatsApp Web with the message filled in, and presses Send.
  4. It marks the message sent in the POS, or not available if the number isn't on WhatsApp.
  5. It waits a few seconds, then moves on to the next one until you press Stop.

Saving customer replies

  1. Someone presses Start Listening.
  2. The extension watches the chat list for chats with unread messages.
  3. It opens those chats one at a time and copies the new text messages from customers.
  4. It saves each message to the POS with the customer's number, your number and the WhatsApp time.
  5. It keeps checking for new messages until you press Stop Listening.
Features

What it does

Sends POS messages from WhatsApp Web

Sends the messages your Store Sync POS has queued, one at a time, from your own WhatsApp number. Each one is marked in the POS, so your team can see what went out.

  • A short countdown before each message and a random pause of a few seconds between messages.
  • Numbers that aren't on WhatsApp are skipped: the extension closes WhatsApp's popup and marks them not available.
  • When the queue is empty it keeps checking, so new messages go out without pressing Start again.
  • Stop at any time. A stopped run never sends a half-finished message.

Saves customer replies to the POS

While listening is on, new text messages from customers are copied into your Store Sync POS, so your team can follow up there.

  • Messages you sent yourself are skipped.
  • Messages that synced to WhatsApp Web are captured even if they were already read on the phone.
  • Only recent messages are read (the last 1 day by default), so old history isn't imported.
  • Each message is saved once. The extension remembers what it has already captured.
  • Chats are opened with a gap of 1–2 minutes between them by default, so WhatsApp Web isn't flooded.

Shows what reached the POS

The Received tab lists every captured message with its save status. If the POS can't be reached, the extension retries on its own.

Uses your POS sign-in

There is nothing extra to log in to. Keep Store Sync POS open and signed in, in the same Chrome window, and the extension uses that session. The sidebar and the toolbar popup both show which company is connected.

Picks up where it left off

  • If WhatsApp Web reloads in the middle of a run, sending resumes with the message it was on.
  • If the connection drops, listening checks for unread chats as soon as it's back online.
  • If WhatsApp Web rebuilds its page, the listener restarts itself.

One click to open

The toolbar popup has an Open WhatsApp Web button. It opens WhatsApp Web in a new tab, or shows the sidebar if WhatsApp Web is already open. The × button hides the sidebar.

Getting started

First run

  1. Sign in to Store Sync POS in Chrome and keep that tab open.
  2. Click the extension icon and choose Open WhatsApp Web.
  3. Sign in to WhatsApp Web with the business's WhatsApp account.
  4. Check that the sidebar says POS connected.
  5. Press Start to send queued messages, and Start Listening to save replies.
Good to know

Requirements and privacy

  • Needs Chrome or Edge on a computer, a Store Sync POS account, and WhatsApp Web signed in.
  • Keep the WhatsApp Web tab open while sending or listening.
  • Queued messages and saved replies go to your Store Sync POS server. They are not sold or used for advertising.
  • The sidebar can place a voice call. The AI call agent, if you turn it on and add your own Gemini or xAI key, sends that call's audio only to the provider you chose.
